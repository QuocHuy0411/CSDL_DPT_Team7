# Tier-1 grammar stopwords (M1) - curated in-repo, one canonical term per line.
#
# Format: UTF-8, one term per line, "#" starts a comment, blank lines ignored.
# Canonical form = NFC + lowercase, compound tokens joined with "_" (same shape
# as engine.tokenizer.max_matching output).
#
# Curation rule: only terms whose primary grammatical function is function-like
# (pronoun, demonstrative, preposition, auxiliary, particle, degree/focus
# adverb, discourse connective). A term is listed here even when
# resources/guard_whitelist.txt protects it, so this file stays a readable
# record of the full grammar inventory; the effective stopword set is
# (this file) minus (guards). See resources/tier1_source.md for the rules, the
# deliberate exclusions and the honest counts.
#
# NOT a repackaged external dictionary: no entry was copied from an unlicensed
# stopword corpus. resources/static_stopwords.txt (C2) is a different,
# configuration-level list and is deliberately not reused here.
