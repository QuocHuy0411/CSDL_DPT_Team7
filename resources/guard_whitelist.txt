# Tier-1 guard whitelist (M1): terms that tier-1 filtering must NEVER remove.
#
# Format: UTF-8, one canonical term per line, "#" starts a comment. Canonical
# form = NFC + lowercase, compounds joined with "_".
#
# Rule applied by engine/tokenizer/stopwords.py: a token survives filtering if
# it is a guard, or if any of its "_"-separated components is a guard. So
# guarding "không" also protects "không_thể", "chẳng_hạn", "vì_dầu" and
# "trước_hết" without listing every compound.
#
# Curation rule: protect every term whose removal can change the truth
# conditions, the polarity or the scope of a query. Everything else that is
# function-like stays in resources/grammar_stopwords.txt and is filtered.
#
# Classes below are the audit trail; the class of each entry is also recorded in
# the metadata() payload of Tier1StopwordFilter.
